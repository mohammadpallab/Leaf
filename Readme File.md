# Leaf - Hyre Landing Page

A responsive and modern landing page inspired by modern UI design standards.

## Project Structure
- `index.html` - HTML document containing page layout.
- `style.css` - Custom CSS styling for dark theme and layout responsiveness.
- `script.js` - Simple JavaScript file for interactive functionality.

## How to Deploy via Mobile Browser (GitHub)
1. Go to your GitHub repository `leaf`.
2. Click **Add file** -> **Create new file**.
3. Create files named `index.html`, `style.css`, `script.js`, and `README.md` individually.
4. Copy-paste the respective code blocks into each file and click **Commit changes**.
5. Enable **GitHub Pages** under repository **Settings > Pages** to host live.
